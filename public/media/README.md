# Media organization

Place approved, web-ready assets in the appropriate folder:

- `projects/<project-slug>/` — case-study hero images, galleries, and approved project video
- `ugc/` — approved UGC video files, posters, captions, and supporting stills
- `photography/` — approved portfolio photographs and captions
- `portraits/` — approved personal portraits
- `branding/logos/` — personal identity and approved brand marks
- `branding/icons/` — interface or identity icons that are not part of the application code
- `fonts/` — properly licensed, web-optimized font files

Use lowercase kebab-case filenames. Optimize images and videos before committing them. Record source, ownership, licensing, attribution, alt text, and credits with the relevant project content. Do not add private working files, unlicensed assets, raw production media, or client material that has not been approved for portfolio use.
